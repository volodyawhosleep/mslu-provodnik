# Проводник МГЛУ

Веб-версия навигатора по корпусам МГЛУ: поиск аудитории и планы этажей.

Сайт (после включения GitHub Pages): https://volodyawhosleep.github.io/mslu-provodnik/

## Как открыть на iPhone

1. Откройте ссылку в Safari.
2. Поделиться → «На экран Домой».

Первый запуск нужен с интернетом. Потом открытые планы могут работать из кэша.

Это неофициальная любительская копия логики Android-приложения `mslu`. Не является сайтом университета.
